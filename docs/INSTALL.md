# Install

## Windows SAPI5

1. Run `MilenaMBROLA-SAPI5-1.0.0-x64.exe`.
2. Finish the installer with administrator rights.
3. Select `Milena - MBROLA` in SAPI-compatible applications.

## NVDA

1. Open `Milena_MBROLA-1.0.0.nvda-addon`.
2. Confirm add-on installation in NVDA.
3. Restart NVDA.
4. Select `Milena - MBROLA` in NVDA speech settings.

## Android

### APK

1. Download `MilenaAndroid-1.0.0-release.apk`.
2. Allow installation from unknown sources if Android asks.
3. Install the APK.
4. Open Android text-to-speech settings and select `Milena`.

### AAB

`MilenaAndroid-1.0.0-release.aab` is meant for store-style distribution or further signing workflows, not direct sideloading.

## Integrity check

Download `Milena-1.0.0-SHA256SUMS.txt` from the GitHub release page and verify the file hashes before installing.
